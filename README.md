# 골프 페널티 정산표 (Golf Penalty Sheet)

## 프로젝트 개요
- **이름**: 골프 페널티 정산표
- **목표**: 골프 모임 회원(약 8명)이 게임에서 져서 내는 페널티(벌금) 금액을 날짜별로 기록·합계하는 엑셀/구글시트형 웹앱
- **배포 URL (프로덕션)**: https://golf-penalty.pages.dev

## 화면 구조
| No | 회원 이름 | 양지번호 | (날짜1) | (날짜2) | ... | 합계 |
|----|-----------|----------|---------|---------|-----|------|
- 1열: No · 2열: 회원 이름 · 3열: **양지번호** · 4열~: 날짜별 금액 · 맨 오른쪽: 회원별 합계
- 맨 아래 행: 날짜별 합계 + 우측 하단 전체 합계

## 컬럼 폭 규격 (글자 수 기준)
- **No**: 숫자 3자리 폭
- **회원 이름**: 한글 6자 폭 (maxlength 6)
- **양지번호**: 6자리 폭 (maxlength 6)
- **금액칸**: placeholder 10자리(`0000000000`), 입력 최대 13자
- 화면 크기·해상도에 따라 글자 크기가 자동 확대되어 4K/8K 화면에서도 선명(고DPI 안티앨리어싱 적용)

## 주요 기능
- **엑셀형 그리드**, 칸 크기 축소, **컬럼 너비 드래그 조절**(헤더 경계선; PC 마우스 + 모바일 터치)
- **골프 친 날짜 기본 1개**(오늘) 자동 생성, **날짜 추가** 버튼으로 무제한 추가
- 이름/양지번호/금액 **셀에서 바로 입력**, 천단위 콤마 자동, 합계 실시간
- **모바일 우선 + PC 반응형**, 이름·합계 열/헤더/합계 행 스크롤 고정
- **자동 저장**(브라우저 localStorage)
- **CSV(엑셀) 내보내기**, 전체 백업(JSON)/복원

## 권한 (중요)
- **일반 사용자 모드**: 비어있는 칸에 **새 입력만** 가능. 이미 입력된 값의 **수정·삭제 불가**. 회원/날짜 삭제·초기화 불가.
- **관리자 모드**: 모든 값 **수정·삭제**, 회원/날짜 삭제, 초기화, 자료실 관리 가능.
  - **관리자 ID**: `admin` / **비밀번호**: `admin1234`
  - 우측 상단 **[관리자]** 버튼 → 로그인 / 관리자 화면의 **[로그아웃]**으로 일반 모드 복귀

## 관리자 자료실
- 이미지 + 이름으로 자료 등록/삭제/크게보기 (회원 사진, 영수증 등)
- 데이터 요약(회원 수·날짜 수·누적 페널티·자료 수)
- 정산표 CSV 내보내기, 전체 백업(JSON), 백업 복원

## 데이터 구조
- **저장소**: 브라우저 localStorage (키: `golf-penalty-sheet-v3`)
- **모델**:
  ```
  {
    members: [{ id, name, phone }],
    dates:   [{ id, iso }],
    cells:   { "memberId|dateId": 금액 },
    manager: { name, phone },
    widths:  { 컬럼키: 너비px },
    assets:  [{ id, name, data(dataURL), ts }]
  }
  ```
- ※ 데이터는 각 기기(브라우저)에 저장됩니다. 여러 기기 실시간 공유는 서버 저장소(D1+R2) 연동 필요.
