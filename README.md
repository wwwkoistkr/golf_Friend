# 골프 페널티 정산표 (Golf Penalty Sheet)

## 프로젝트 개요
- **이름**: 골프 페널티 정산표
- **목표**: 골프 모임 회원(약 8명)이 게임에서 져서 내는 페널티(벌금) 금액을 날짜별로 기록하고 합계를 자동 계산하는 엑셀/구글시트 형식의 웹앱
- **레이아웃**:
  - 1번째 컬럼: No (회원 번호)
  - 2번째 컬럼: **회원 이름** (셀에서 바로 입력)
  - 3번째 컬럼: **전화번호** (셀에서 바로 입력)
  - 4번째 컬럼부터: **날짜별 금액 입력칸** (가로축 = 골프 친 날짜)
  - 맨 오른쪽 컬럼: **회원별 합계** (자동 계산, 화면 고정)
  - 맨 아래 행: **날짜별 합계** + 우측 하단 **전체 합계** (자동 계산, 화면 고정)
- **기본 8명 빈 행**으로 시작, 회원/날짜 자유롭게 추가·삭제

## 기능 진입 경로
- `GET /` : 메인 앱 (단일 페이지, 모든 기능 포함)
- 상단 버튼: **회원 추가 / 날짜 추가 / 엑셀저장(CSV) / 초기화**
- 담당자 이름·전화번호 입력란 (상단 바)
- 각 행 No 옆 ✕ = 회원 행 삭제 / 날짜 헤더 ✕ = 날짜 열 삭제
- 전화번호는 CSV로 내보내 엑셀에서 활용 가능

## 특징
- **엑셀/구글시트 스타일** 그리드, 큰 글씨로 보기 편함
- 이름/전화번호/금액 모두 셀에서 **바로 인라인 입력**
- 금액 입력 시 **천단위 콤마 자동**, 합계 실시간 갱신
- 이름 열·합계 열·헤더·합계 행이 **스크롤해도 고정**
- **모바일 + PC 반응형** (모바일에선 버튼 아이콘화)
- 입력 내용 **자동 저장** (브라우저 localStorage)

## 데이터 구조
- **저장소**: 브라우저 localStorage (키: `golf-penalty-sheet-v2`)
- **모델**:
  ```
  {
    members: [{ id, name, phone }],   // 기본 8행
    dates:   [{ id, iso }],           // "YYYY-MM-DD", 날짜순 정렬
    cells:   { "memberId|dateId": 금액 },
    manager: { name, phone }
  }
  ```

## 사용 방법
1. 회원 이름과 전화번호를 각 행에 입력 (기본 8칸, 부족하면 "회원 추가")
2. "날짜 추가"로 골프 친 날짜 등록 (가로로 열이 생김)
3. 각 칸에 그날 회원이 낸 페널티 금액 입력
4. 회원별 합계(오른쪽), 날짜별 합계(아래), 전체 합계(우측 하단) 자동 계산
5. 필요 시 "엑셀저장"으로 CSV 내려받기
